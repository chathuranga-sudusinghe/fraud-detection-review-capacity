# Reference Register

Master list of every source used by this research project. Other documents cite sources by **Reference ID** (e.g. `REF-005`), so each claim can be traced back to this register when writing the dissertation. Every entry has its own link target, written in lower case: for example [`references.md#ref-047`](#ref-047).

Entries are grouped by source type and listed by ID within each group. Each entry's **Note** records how the citation was checked and, where documented, which text was checked for content; the verification passes are listed in [Appendix B](#appendix-b--verification-passes).

**Provenance.** REF-056–REF-060 are context sources for the literature review, read at abstract level. REF-086–REF-102 were selected by the structured search documented in [`literature-search-method.md`](literature-search-method.md) and are compared in [`literature-evidence-matrix.md`](literature-evidence-matrix.md).

## Verification status

| Status | Meaning |
|---|---|
| **Verified** | Bibliographic details (authors, title, venue, volume/issue/pages, year, DOI) checked against the publisher, the Crossref DOI registry, or official proceedings. For Greenwich sources, the page or document was read directly. |
| **Partially verified** | Some details confirmed, others not. The note says what is still missing. Do not use as sole support for a central claim until upgraded. |
| **Unverified** | Not yet checked, or not accessible. **Must not be used as evidence** until checked. |

"Verified" means the **citation** is correct. The *interpretation* of each source in project documents must still be checked against the full text before it appears in the dissertation.

**Inclusion rules.** Practitioner web pages (e.g. vendor blogs, unreviewed Kaggle notebooks) and non-peer-reviewed preprints are not added as evidence. Sources considered and not added:

- non-peer-reviewed preprints found by the structured search, e.g. a Booking.com study of tabular Transformers (arXiv:2405.13692);
- Elbadraoui et al.'s 2026 ICCSC conference extension (doi:10.1109/ICCSC71566.2026.11650605), whose content was seen only as a secondary-source abstract; REF-080 is the verified journal study it builds on.

Initial evidence base: the reference list of `notebooks/01_dataset_feasibility_audit.ipynb`. Notebook reference numbers `[L1]`–`[L47]` and `[G1]`–`[G5]` are mapped to register IDs in [Appendix A](#appendix-a--mapping-from-feasibility-notebook-reference-numbers).
